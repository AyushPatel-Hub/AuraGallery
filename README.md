Aura Gallery
Aura Gallery is a responsive wallpaper web application built as a practice project while learning HTML, CSS, and JavaScript. It allows users to search for high-quality wallpapers using the Unsplash API and displays the results dynamically in a clean and modern interface.
🚀 Features
🔍 Search wallpapers by keyword
🖼️ Dynamic image loading using the Unsplash API
📱 Responsive design for desktop and mobile devices
⚡ Interactive user interface with JavaScript
🎨 Modern layout designed using CSS Flexbox
🌐 Deployed on GitHub Pages

🎯 Purpose
This project was created to strengthen my front-end development skills by applying core web technologies in a real-world application. It demonstrates my understanding of responsive design, API integration, and dynamic content rendering while building a visually appealing wallpaper gallery.
