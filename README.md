🌌 Aura Gallery
A dynamic, responsive wallpaper web application built as a practical project to master foundational web development technologies (HTML5, CSS3, and JavaScript). Aura Gallery leverages the Unsplash API to provide users with a seamless, real-time image search experience alongside curated visual sections.

🚀 Project Overview
Aura Gallery was developed to bridge the gap between static design and dynamic user interaction. The application allows users to search for high-quality, high-resolution wallpapers on demand while displaying curated image collections across different thematic sections of the page.

The primary goal of this project was to implement core frontend concepts—such as asynchronous API handling, responsive styling layouts, and direct DOM manipulation—into a functional, real-world utility.

🛠️ Features
Dynamic Live Search: Uses asynchronous JavaScript to fetch and display high-resolution wallpapers in real-time based on user input.

Powered by Unsplash API: Integrated via secure HTTP requests to handle structured JSON responses and render images dynamically.

Curated Content Sections: Features structured galleries utilizing direct image URLs from external web resources to organize different wallpaper categories.

Responsive Modern Design: Fully optimized layout that adapts fluidly across mobile, tablet, and desktop screens.

💻 Tech Stack & Concepts Learned
This project served as an end-to-end practice environment for mastering the core pillars of frontend web development:

📑 HTML5 (Structure)
Semantic markup (<header>, <section>, <main>, <footer>) for better SEO and accessibility.

Structured forms and input handling for user search queries.

🎨 CSS3 (Styling & Layout)
Flexbox & Grid Layouts: Employed extensively to build a fluid, alignment-perfect image grid system that handles variable image dimensions gracefully.

Modern UI Aesthetics: Implemented custom properties (CSS variables), hover transitions, smooth scaling effects, and clean typography to enhance the visual experience.

⚡ JavaScript (Functionality & Logic)
Asynchronous JS (Fetch API): Handled asynchronous fetch() requests to securely communicate with the Unsplash API endpoint, managing async/await flows and parsing JSON responses.

DOM Manipulation: Dynamically creating, appending, and updating HTML nodes based on the API data return.

Event Listeners: Implemented robust event handling for search submission, input changes, and click interactions.

Functional Programming: Organized the codebase into reusable, single-responsibility functions to maintain clean, scalable code.

🌐 Deployment
